# Step 1. Set up VS Code (10 minutes)

1. **VS Code** from <https://code.visualstudio.com>, signed in to GitHub (Accounts icon, bottom left).
2. **GitHub Copilot:** open the Copilot Chat panel and sign in. It is free for verified students: apply at <https://education.github.com/pack>. Until you are verified, Copilot Free works right away. In the chat panel, choose **Agent** mode so it can create files and run commands.
3. **Your repository:** on this repository's GitHub page, click **Use this template > Create a new repository** (public). In VS Code: **Source Control > Clone Repository**, and pick it.
4. **Be on UW Wi-Fi or the Husky OnNet VPN.** The class database is only reachable from the UW network.
